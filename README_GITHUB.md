# ZiruPDF 网站升级版 2.1.19

纯静态网站，无构建步骤。将此文件夹内全部内容覆盖上传到现有网站仓库，包含新的 pdf、image、guides 文件夹及完整 assets。域名以 CNAME 为准。桌面软件没有修改，软件版本仍在 assets/js/config.js 单独维护。

工具使用薄静态页面和共享脚本，保留全部旧 HTML 入口。旧 query 入口由 site.js 按 mode 更新对应 canonical，未做强制跳转。新增页面使用独立目录网址、描述、分享标签、工具结构化数据。sitemap.xml 只列已实现页面，不含尚未配置的赞助页或 PDF 压缩占位页。

两个新增工具：图片压缩到指定大小，先调质量再按用户允许范围缩小尺寸，输出实际大小和预览，失败不作为成功下载；证件复印件用途水印，支持 PDF 输入，照片先转 PDF，采用接收方/用途/日期模板。水印不能保证防止盗用。

所有处理在浏览器本地完成，无广告或第三方统计。PDF.js、pdf-lib、字体和解码资源随包分发，许可位于 assets/vendor。

本地预览：python -m http.server 8000，再打开 http://127.0.0.1:8000/。请从网站根目录启动；页面 base 地址为 /，面向现有独立域名根目录部署。

维护标题与说明在对应目录 index.html，处理逻辑在 assets/js 中。下载按钮默认进入官方最新 Release，不需要随每次软件版本改安装包直链。部署后可在 Search Console 提交 sitemap.xml；本次未代为发布或提交。

验证结果：13 项在线工具生成检查、指定大小成功/失败、用途水印四种旋转方向、旧入口 canonical、手机布局、全部页面内部链接与元信息均通过。浏览器测试期间只有本站静态资源请求与本地 Blob 读取，无文件上传或第三方请求。

## 2.1.20 界面调整
