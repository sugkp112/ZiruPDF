# ZiruPDF 网站升级版 2.1.19

纯静态网站，无构建步骤。将此文件夹内全部内容覆盖上传到现有网站仓库，包含新的 pdf、image、guides 文件夹及完整 assets。域名以 CNAME 为准。桌面软件没有修改，软件版本仍在 assets/js/config.js 单独维护。

工具使用薄静态页面和共享脚本，保留全部旧 HTML 入口。旧 query 入口由 site.js 按 mode 更新对应 canonical，未做强制跳转。新增页面使用独立目录网址、描述、分享标签、工具结构化数据。sitemap.xml 只列已实现页面，不含尚未配置的赞助页或 PDF 压缩占位页。

两个新增工具：图片压缩到指定大小，先调质量再按用户允许范围缩小尺寸，输出实际大小和预览，失败不作为成功下载；证件复印件用途水印，支持 PDF 输入，照片先转 PDF，采用接收方/用途/日期模板。水印不能保证防止盗用。

所有处理在浏览器本地完成，无广告或第三方统计。PDF.js、pdf-lib、字体和解码资源随包分发，许可位于 assets/vendor。

本地预览：python -m http.server 8000，再打开 http://127.0.0.1:8000/。请从网站根目录启动；页面 base 地址为 /，面向现有独立域名根目录部署。

维护标题与说明在对应目录 index.html，处理逻辑在 assets/js 中。下载按钮默认进入官方最新 Release，不需要随每次软件版本改安装包直链。部署后可在 Search Console 提交 sitemap.xml；本次未代为发布或提交。

验证结果：13 项在线工具生成检查、指定大小成功/失败、用途水印四种旋转方向、旧入口 canonical、手机布局、全部页面内部链接与元信息均通过。浏览器测试期间只有本站静态资源请求与本地 Blob 读取，无文件上传或第三方请求。

## 2.1.20 界面调整

## web-2026.10 官网改版
- 首页改为：顶部导航（首页 / 功能 / 在线工具 / 使用帮助 / 免费下载）、首屏介绍与下载按钮、真实软件截图、四个功能类别、四项优势、常用在线工具入口。首页不写版本号、功能数量或“最新更新”。
- 功能页按六个稳定类别介绍（阅读与批注、编辑与页面管理、Office 转换、OCR 与扫描、压缩保护与水印、批量处理），内容依据 2.1.43 源码中的工具目录核对；旧锚点 #desktop-tool-1…16 继续有效。
- 版本信息集中到根目录 version.json（桌面软件检查更新使用的同一文件，新增 installer、size 字段，原有字段不变）；config.js 不再包含版本。下载页与首页按钮由 site.js 读取 version.json 填写，读取失败时回退到 GitHub Releases。
- 全站导航与页脚统一；所有在线工具、教程、FAQ、隐私、许可、赞助和旧 .html / ?mode= 入口保留，工具处理脚本未改动。
- 维护方法见“网站覆盖说明.txt”。

## web-2026.11 多语言与联系页
- 网站分为 /zh/、/ja/、/en/ 三个独立语言地址，每页带 hreflang（zh-Hans / ja / en / x-default）与自身 canonical，sitemap.xml 列出全部语言版本。
- 根地址 / 为语言入口（按已选语言或浏览器语言跳转，并显示三个语言链接）；页头语言菜单与页脚语言链接切换到同一页面的其他语言。
- 旧地址经 _redirects 301 跳转到 /zh/ 对应页面，旧路径保留 noindex 跳转页作为后备；?mode= 旧工具页由脚本按 mode 跳转。
- 新增联系页面，与软件“帮助 → 联系我们”一致：联系页面（zirulab.org/contact）、ZiruPDF 官网、定制与批量处理（zirulab.org/services）；导航、页脚、FAQ 均有入口。
- 全部页面与 15 个在线工具已翻译为日文和英文；工具界面文字由 assets/js/lang.js 按语言查表，处理逻辑不变。日文 / 英文页面使用对应语言界面的真实软件截图。
