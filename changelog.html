更新日志

这里只保留对公开用户有意义的主要变化。

2.0.41 · 2026-10-07

新增“保护 PDF”：可设置打开密码、限制打印 / 复制 / 编辑，以及移除密码；新增“数字签名”：可使用 .p12 / .pfx 证书对 PDF 进行真正的数字签名，并在阅读器中显示签名状态。

2.0.40

重做扫描件 OCR：按页面判断、支持本页 / 选区 / 所选页面 / 全部扫描页识别；改进日文、列表、表格和分栏识别；PDF 编辑器可识别并修改扫描文字，保存时尽量只替换改动区域，减少重影。

2.0.39

改进批注和书签跨版本恢复；修正实际尺寸打印；支持更大的 PDF 文件。

2.0.37–2.0.38

改进 PDF 阅读器缩放与翻页显示；新增手形拖动、文字选择、阅读批注和书签；完善打印设置与批注在编辑 / 撤销后的保留。

2.0.36

改进 Windows 桌面版设置与用户状态的跨重启保存，并保持浏览器模式与桌面模式的存储相互独立；继续完善 ZiruPDF 发布准备与兼容性。

2.0.35

产品名称统一为 ZiruPDF，完善免费使用但非开源的许可说明，并保持 FreeDoc / ZiruDoc 旧版本升级兼容。

2.0.30–2.0.34

持续改进 PDF 编辑高清渲染、字体与版式处理、多语言、安装器、许可证与发布流程。
