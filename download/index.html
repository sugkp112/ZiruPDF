Windows 安装提示
由于 ZiruPDF 目前尚未使用商业代码签名证书，首次运行安装程序时，Windows 可能显示“未知发布者”或“Windows 已保护你的电脑”。这并不代表 Windows 已检测到恶意程序。请仅从 zirupdf.zirulab.org 或 ZiruPDF 官方 GitHub Release 下载。若出现 SmartScreen 提示，可点击“更多信息” → “仍要运行”继续安装。
