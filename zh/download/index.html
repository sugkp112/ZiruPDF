安装提示

ZiruPDF 目前尚未使用商业代码签名证书，首次运行安装程序时，Windows 可能显示“未知发布者”或“Windows 已保护你的电脑”。这表示 Windows 无法确认发布者身份，并不等于检测到恶意程序，但也说明需要你自己确认文件来源。

运行前请先确认

  • 只从本页按钮或 ZiruPDF 官方 GitHub Releases（github.com/sugkp112/ZiruPDF）下载，不使用第三方下载站、网盘或他人转发的文件。
  • 文件名和文件大小与本页显示的版本信息一致（右键文件 → 属性可查看大小）。
  • SHA-256 校验值与本页一致：在 PowerShell 中运行 Get-FileHash 文件路径 -Algorithm SHA256，核对结果是否为 。

以上都确认无误后，才在 SmartScreen 提示中选择“更多信息” → “仍要运行”。如果来源不明、文件名或大小不一致，或杀毒软件报告威胁，请不要运行，删除该文件后重新从官方渠道下载。
