ZiruPDF 功能

阅读、编辑、转换、OCR 与批量处理，常用的 PDF 工作都可以在 Windows 桌面版中完成。

PDF 阅读与批注

舒适地阅读和审阅 PDF，标记内容并保存在本机。

  • 多文件标签、页面缩略图、书签与全文搜索
  • 单页、双页和连续阅读，支持全屏演示
  • 荧光笔、彩色笔、文字批注和放大镜
  • 逐页对比两个 PDF 版本，查看差异
  • 打印 PDF

PDF 编辑与页面管理

直接修改 PDF 内容，并按需要整理页面。

  • 修改文字和图片，添加高亮、批注与图形
  • 合并多个 PDF，或按页码范围拆分、提取
  • 拖动排序、旋转、删除和裁剪页面
  • 自动删除空白页，统一页面尺寸
  • 添加页码、页眉和页脚

PDF 与 Office 转换

在 PDF 和常用办公格式之间相互转换。

  • PDF 转 Word、Excel、PowerPoint
  • Word、Excel、PowerPoint 转 PDF
  • PDF 导出为 PNG、JPG、TIFF 图片
  • 多张图片合成一个 PDF
  • 提取 PDF 中的文字、图片、表格和附件

OCR 与扫描文档

让扫描件和图片中的文字可以搜索、复制和编辑。

  • 为扫描 PDF 添加文字层，生成可搜索 PDF
  • 识别中文、日文和英文
  • 图片或扫描件转为可编辑的 Word
  • 表格识别并导出为 Excel
  • 手机扫描，自动纠偏、裁边和去黑边

PDF 压缩、保护与水印

减小文件体积，保护文件内容，标明文件用途。

  • 压缩 PDF，减小文件体积
  • 设置打开密码，限制打印、复制和编辑
  • 使用证书为 PDF 添加数字签名
  • 添加文字水印或图片图章

自动化任务与批量处理

把重复的工作交给批量处理，一次完成多个文件。

  • 把多个处理步骤组合成任务，可保存后重复使用
  • 处理前预览效果，确认后批量执行
  • 同一个操作一次处理多个文件
  • 图片批量缩放、旋转和转换格式
