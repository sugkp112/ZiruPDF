プライバシーについて — ZiruPDF

ZiruPDF の基本方針は、文書をできるかぎりユーザーのパソコン上で処理することです。

文書の処理

PDF、Office、画像、OCR の主な処理は、ローカルのデスクトッププログラムとローカルエンジンで行われます。これらのデスクトップ機能を使うために、ZiruPDF のウェブサイトへ個人の文書をアップロードする必要はありません。

オンラインツール

オンラインの PDF・画像ツールはすべてブラウザ内で処理します。ファイルの内容、ファイル名、処理結果はサーバーに送信されません。選択したファイルは現在のページ内でのみ使われ、クリアするかページを閉じると保持されません。ダウンロードした結果はご自身のデバイスに保存されます。

広告とアクセス解析

現在、このサイトには広告、サードパーティのアクセス解析、広告追跡用の Cookie は導入していません。今後、ガイドや説明ページに広告を導入する場合は、事前にこのプライバシー説明を更新し、地域の要件に応じて同意管理を設定します。ファイル処理ページは引き続き広告なし、サードパーティの解析スクリプトなしとします。

アカウント

ZiruPDF デスクトップ版の主な機能は、アカウント登録なしで使えます。

ネットワーク接続

既定で自動的に行う外部への通信は、主にオフにできるバージョン更新チェックです。ユーザーが公式サイト、GitHub、ダウンロードページを開いたり、オプションのコンポーネントをインストールしたりすると、該当するネットワーク上のリソースにアクセスします。スマートフォンスキャン機能は、ローカルネットワーク内で一時的な接続を確立することがあります。

ウェブサイトへのアクセス

ZiruPDF の公式サイトや GitHub にアクセスした際、Cloudflare や GitHub などのサービスが、それぞれのポリシーに従って必要なネットワークログやセキュリティログを記録することがあります。

サードパーティのコンポーネント

ZiruPDF はさまざまなサードパーティのコンポーネントを使用しています。関連するライセンスと告知は正式なインストーラーに同梱されています。

ポリシーの更新

今後、アカウント、オンラインでの文書処理、テレメトリ、広告、新しい支払いの仕組みを導入する場合は、このプライバシー説明を更新します。
