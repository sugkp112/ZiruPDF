今回は何をしますか？

ファイルを選択 → 設定とプレビュー → ダウンロード

画像を指定サイズに圧縮

例：200 KB 以下に圧縮し、プレビューしてからダウンロード。

ツールを開く →

PDF の回転・削除・並べ替え

向きを直し、不要なページを削除し、順番を入れ替えます。

ツールを開く →

身分証明書のコピーに透かしを入れる

例：「入社手続き専用」。

ツールを開く →

PDF 処理

PDF 結合ファイルの順番を調整してひとつの PDF に↗抽出／分割ページを選んで抽出、または 1 ページずつ保存↗PDF を画像に選択したページを PNG または JPG で書き出し↗透かし／ページ番号文字・位置・透明度を自由に設定↗

画像処理

画像を PDF に変換複数の画像を順番どおりに PDF にまとめる↗画像のリサイズ縦横比を保ってピクセルサイズを変更↗形式変換PNG・JPG・WebP を相互変換↗トリミング／回転枠をドラッグして切り抜き、向きを調整↗画像の圧縮画質を調整し、実際の出力サイズを確認↗PNG を ICO に複数サイズの Windows アイコンを作成↗

一致するツールが見つかりません。「結合」「画像」「透かし」などで試してください。
