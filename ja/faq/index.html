よくある質問 — ZiruPDF

ZiruPDF は無料ですか？

はい。個人、教育、企業、業務用途のいずれでも無料で使え、主な機能に回数による課金はありません。

ZiruPDF はオープンソースですか？

いいえ。ZiruPDF は無料で使えますが、アプリのソースコードは公開していません。サードパーティのオープンソースコンポーネントは、それぞれのライセンスに従って配布されます。

ファイルはサーバーにアップロードされますか？

PDF、Office、OCR、画像の主な処理は、ローカルのデスクトッププログラムとローカルエンジンで行われます。変換のために文書を ZiruPDF のウェブサイトへアップロードする必要はありません。

対応 OS は？

現在は主に 64 ビット版 Windows 10 / 11 を対象としています。

インストール時に Windows のセキュリティ警告が出るのはなぜですか？

ZiruPDF はまだ商用のコード署名証明書を使用していないため、Windows に「不明な発行元」や SmartScreen の警告が表示されることがあります。これはマルウェアが検出されたという意味ではありません。まず、インストーラーが zirupdf.zirulab.org または ZiruPDF 公式 GitHub Release から入手したものであり、ファイル名とサイズがダウンロードページの表示と一致していることを確認し、問題がなければ「詳細情報」→「実行」を選んでください。入手元が不明な場合、ファイル情報が一致しない場合、またはウイルス対策ソフトが脅威を報告した場合は実行しないでください。

Python のインストールは必要ですか？

いいえ。正式なインストーラーに ZiruPDF の実行に必要なコンポーネントが含まれています。

Office から PDF への変換に Microsoft Office は必要ですか？

一部の高忠実度な Office 変換では、パソコンにある Microsoft Office を優先して使用します。利用できるコンポーネントに応じて、ソフトが適切な処理方法を選びます。

スキャンした PDF の文字を検索できますか？

はい。OCR でスキャン PDF に検索可能なテキスト層を作成できます。仕上がりはスキャンの品質や言語によって変わります。

ZiruPDF のインストーラーを他のダウンロードサイトにアップロードしてもよいですか？

ZiruLab の書面による許可なく、インストーラーを再ホストすることはできません。ZiruPDF 公式サイトや公式 GitHub Release へのリンクは自由に共有できます。

最新版はどこでダウンロードできますか？

zirupdf.zirulab.org の公式ダウンロードページからどうぞ。インストールファイルは公式 GitHub Releases で提供しています。
