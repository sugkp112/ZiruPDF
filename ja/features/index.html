ZiruPDF の機能

閲覧、編集、変換、OCR、一括処理。よくある PDF 作業は Windows デスクトップ版ですべて行えます。

PDF の閲覧と注釈

PDF を快適に読んで確認し、内容に印を付けてパソコンに保存できます。

  • 複数ファイルのタブ、ページのサムネイル、しおりと全文検索
  • 単一ページ・見開き・連続表示、全画面プレゼンテーションにも対応
  • 蛍光ペン、カラーペン、テキスト注釈、拡大鏡
  • 2 つの PDF をページごとに比較し、違いを確認
  • PDF の印刷

PDF の編集とページ管理

PDF の内容を直接修正し、必要に応じてページを整理します。

  • 文字や画像の修正、ハイライト・注釈・図形の追加
  • 複数の PDF の結合、ページ範囲での分割・抽出
  • ドラッグでの並べ替え、回転、削除、トリミング
  • 白紙ページの自動削除、ページサイズの統一
  • ページ番号、ヘッダー、フッターの追加

PDF と Office の変換

PDF とよく使うオフィス形式を相互に変換します。

  • PDF を Word、Excel、PowerPoint に変換
  • Word、Excel、PowerPoint を PDF に変換
  • PDF を PNG、JPG、TIFF 画像として書き出し
  • 複数の画像をひとつの PDF にまとめる
  • PDF から文字、画像、表、添付ファイルを抽出

OCR とスキャン文書

スキャンした文書や画像の文字を、検索・コピー・編集できるようにします。

  • スキャン PDF にテキスト層を追加し、検索可能な PDF を作成
  • 中国語、日本語、英語を認識
  • 画像やスキャン文書を編集可能な Word に変換
  • 表を認識して Excel に書き出し
  • スマートフォンでスキャンし、傾き補正・余白トリミング・黒枠除去を自動で

PDF の圧縮・保護・透かし

ファイルサイズを小さくし、内容を保護し、用途を明示します。

  • PDF を圧縮してファイルサイズを削減
  • パスワードを設定し、印刷・コピー・編集を制限
  • 証明書を使って PDF にデジタル署名
  • 文字の透かしや画像のスタンプを追加

自動化タスクと一括処理

繰り返しの作業は一括処理に任せて、複数のファイルを一度に仕上げます。

  • 複数の処理手順をタスクにまとめ、保存して繰り返し使用
  • 処理前に結果をプレビューし、確認してから一括実行
  • 同じ操作で複数のファイルを一度に処理
  • 画像の一括リサイズ、回転、形式変換

処理するファイルが 1～2 個だけなら、結合・分割・ページ整理・透かし・画像ツールをブラウザで直接使えます。
