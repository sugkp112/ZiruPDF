身分証明書のコピーに用途を明記する方法

ファイルをアップロードせずに使えるブラウザツールです。

提出先・用途・日付を入力

使用する権利のある PDF のコピーを選び、提出先、用途、日付を入力します。たとえば「〇〇株式会社の入社手続き専用」のようにします。写真の場合は、先に画像を PDF に変換するツールで変換できます。

範囲と鮮明さを確認

テンプレートは文字をページ全体に繰り返し配置します。色、透明度、大きさを調整し、ページの複数の領域を覆っていること、同時に判読が必要な重要な項目を隠していないことを確認してください。ダウンロード後にもう一度開き、各ページを確認しましょう。

透かしの限界を理解する

透かしは用途を示すのに役立ちますが、切り取りや改変をされる可能性があり、不正利用を防げる保証はありません。提出先が透かし入りの書類を受け付けるかどうかも、ご自身で確認してください。透かしを入れたからといって、不明な相手にファイルを送らないでください。
