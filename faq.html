常见问题

ZiruPDF 是免费的吗？

是。个人、教育、企业以及商业工作场景均可免费使用，核心功能不按次数收费。

ZiruPDF 是开源软件吗？

不是。ZiruPDF 免费使用，但应用源码不公开。第三方开源组件仍按各自许可证分发。

文件会上传服务器吗？

核心 PDF、Office、OCR 与图片处理由本地桌面程序和本地引擎完成，文档不需要上传到 ZiruPDF 网站进行转换。

支持哪些系统？

当前主要面向 64-bit Windows 10 / 11。

为什么安装时 Windows 会显示安全提示？

ZiruPDF 目前尚未使用商业代码签名证书，因此 Windows 可能显示“未知发布者”或 SmartScreen 提示。这不等同于检测到恶意程序。请确认安装包来自 zirupdf.zirulab.org 或 ZiruPDF 官方 GitHub Release；如确认来源无误，可点击“更多信息” → “仍要运行”继续安装。

必须安装 Python 吗？

不需要。正式安装包包含运行 ZiruPDF 所需的程序组件。

Office 转 PDF 需要 Microsoft Office 吗？

部分高保真 Office 转换优先使用本机 Microsoft Office；软件也会根据可用组件提供相应处理路径。

扫描 PDF 可以搜索文字吗？

可以。OCR 可以为扫描 PDF 建立可搜索文字层，实际效果会受扫描质量和语言影响。

可以把 ZiruPDF 安装包上传到其他下载站吗？

未经 ZiruLab 书面许可，不可以重新托管安装包。可以自由分享 ZiruPDF 官方网站或官方 GitHub Release 链接。

在哪里下载最新版？

请通过 zirupdf.zirulab.org 进入官方下载页，安装文件由官方 GitHub Releases 提供。
