ZiruPDF features

Read, edit, convert, OCR and batch-process — everyday PDF work can all be done in the Windows desktop app.

Reading and annotation

Read and review PDFs comfortably, mark up content and keep your notes on this computer.

  • Tabs for multiple files, page thumbnails, bookmarks and full-text search
  • Single-page, two-page and continuous views, plus full-screen presentation
  • Highlighter, colour pen, text notes and magnifier
  • Compare two PDF versions page by page to see what changed
  • Print PDFs

PDF editing and page management

Edit PDF content directly and organise pages as needed.

  • Edit text and images; add highlights, comments and shapes
  • Merge several PDFs, or split and extract by page range
  • Reorder by dragging, rotate, delete and crop pages
  • Remove blank pages automatically and unify page sizes
  • Add page numbers, headers and footers

PDF and Office conversion

Convert between PDF and common office formats.

  • PDF to Word, Excel and PowerPoint
  • Word, Excel and PowerPoint to PDF
  • Export PDF pages as PNG, JPG or TIFF images
  • Combine several images into one PDF
  • Extract text, images, tables and attachments from PDFs

OCR and scanned documents

Make text in scans and images searchable, copyable and editable.

  • Add a text layer to scanned PDFs to make them searchable
  • Recognises Chinese, Japanese and English
  • Turn images or scans into editable Word documents
  • Recognise tables and export them to Excel
  • Scan with your phone, with automatic deskew, cropping and black-border removal

Compress, protect and watermark

Make files smaller, protect their content and mark their purpose.

  • Compress PDFs to reduce file size
  • Set an open password and restrict printing, copying and editing
  • Digitally sign PDFs with a certificate
  • Add text watermarks or image stamps

Automated tasks and batch processing

Hand repetitive work to batch processing and finish many files at once.

  • Combine several steps into a task and save it for reuse
  • Preview the result first, then run the batch once confirmed
  • Apply the same operation to many files at once
  • Batch resize, rotate and convert images

Only need to handle a file or two? Merging, splitting, page organising, watermarks and image tools also work right in your browser.
