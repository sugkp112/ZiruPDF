Installation notes

ZiruPDF does not yet use a commercial code-signing certificate, so when you first run the installer Windows may show "Unknown publisher" or "Windows protected your PC". This means Windows cannot confirm who published the file — it does not mean malware was detected — but it also means you need to check where the file came from yourself.

Before running it, check that

  • you downloaded it only from the button on this page or from the official ZiruPDF website (zirupdf.zirulab.org) — not from another download site, a cloud drive or a file someone forwarded to you.
  • the file name and size match the version information shown on this page (right-click the file → Properties to see its size).
  • the SHA-256 checksum matches this page: run Get-FileHash path-to-file -Algorithm SHA256 in PowerShell and check that the result is .

Only when all of the above check out, choose "More info" → "Run anyway" in the SmartScreen prompt. If the source is unknown, the file name or size does not match, or your antivirus reports a threat, do not run it — delete the file and download it again from the official source.
