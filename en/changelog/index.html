Changelog — ZiruPDF

Only the main changes that matter to users are listed here.

2.1.42

Added custom image compression quality and clearer batch-processing messages; fixed restoring the selected file when returning to the reader with several files, reduced repeated parsing of the same file, and the reading position is now saved before switching tools.

2.1.18

Improved reading modes, zoom, markup and slide viewing; the sidebar can be resized; bottom buttons stay visible but greyed out when no document is open. Further fixes to browsing interaction and stability.

2.0.36

Settings and user state in the Windows desktop app are now kept across restarts, with storage for browser mode and desktop mode kept separate; further work on release preparation and compatibility.

2.0.35

The product name is now ZiruPDF everywhere; the license notes explaining that it is free but not open source were improved, and upgrades from older FreeDoc / ZiruDoc versions remain compatible.

2.0.30–2.0.34

Ongoing improvements to high-resolution rendering in the PDF editor, font and layout handling, languages, the installer, licensing and the release process.
