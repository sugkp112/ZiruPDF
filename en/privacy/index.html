Privacy — ZiruPDF

ZiruPDF's core principle is to process documents on the user's own computer wherever possible.

Document processing

The main PDF, Office, image and OCR processing is done by the local desktop program and local engines. The ZiruPDF website does not require you to upload private documents to use these desktop features.

Online tools

All online PDF and image tools process files in your browser. File contents, file names and results are not sent to a server; selected files are used only within the current page and are not kept after you clear or close it. Downloaded results are saved on your own device.

Advertising and analytics

This site currently has no advertising, no third-party analytics and no ad-tracking cookies. If advertising is ever added to guide or information pages, this privacy notice will be updated first and consent management will be set up as required in each region; the file-processing pages will remain free of ads and third-party analytics scripts.

Accounts

The core features of the ZiruPDF desktop app can be used without registering an account.

Network connections

By default, the automatic outgoing requests are mainly the update check, which can be turned off. When you open the website or the download page, or install optional components, the corresponding network resources are accessed. The phone-scan feature can set up a temporary connection within your local network.

Website visits

When you visit the ZiruPDF website, services such as Cloudflare and other relevant providers may keep necessary network and security logs according to their own policies.

Third-party components

ZiruPDF uses a number of third-party components. Their licenses and notices are included with the official installer.

Policy updates

If accounts, online document processing, telemetry, advertising or new payment mechanisms are added in the future, this privacy notice will be updated accordingly.
