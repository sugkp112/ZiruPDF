FAQ — ZiruPDF

Is ZiruPDF free?

Yes. It is free for personal, educational, business and commercial use, and the core features are not charged per use.

Is ZiruPDF open source?

No. ZiruPDF is free to use, but the application source code is not published. Third-party open-source components are still distributed under their own licenses.

Are files uploaded to a server?

Core PDF, Office, OCR and image processing is done by the local desktop program and local engines. Documents do not need to be uploaded to the ZiruPDF website for conversion.

Which systems are supported?

Currently mainly 64-bit Windows 10 / 11.

Why does Windows show a security warning during installation?

ZiruPDF does not yet use a commercial code-signing certificate, so Windows may show "Unknown publisher" or a SmartScreen warning. This does not mean malware was detected. First make sure the installer came from zirupdf.zirulab.org or the official ZiruPDF GitHub Release and that its file name and size match the download page; only then choose "More info" → "Run anyway". If the source is unknown, the file details do not match or your antivirus reports a threat, do not run the file.

Do I need to install Python?

No. The official installer includes everything ZiruPDF needs to run.

Does Office-to-PDF conversion need Microsoft Office?

Some high-fidelity Office conversions use Microsoft Office on your computer first; otherwise the app chooses a processing route based on the components available.

Can I search the text of a scanned PDF?

Yes. OCR can add a searchable text layer to scanned PDFs; results depend on scan quality and language.

May I upload the ZiruPDF installer to other download sites?

Not without written permission from ZiruLab. You are welcome to share links to the official ZiruPDF website or the official GitHub Release.

Where can I download the latest version?

Use the official download page at zirupdf.zirulab.org; installer files are provided through the official GitHub Releases.
