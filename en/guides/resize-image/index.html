Resizing images: choosing a size

Browser tools that work without uploading your files.

  1. Choose images and enter the longest edge in pixels.
  2. Check the original size and the processed preview.
  3. After creating, download each PNG.

How do I choose a size?

For web images, start with 1200–1600 pixels and check at the actual display size. Pixel size is not print size; printing also depends on paper size and resolution.

Will the image be distorted?

The tool keeps the aspect ratio and never enlarges small images. Output is PNG with transparency kept. PNG is not guaranteed to be smaller; this tool changes pixel size and is not a dedicated image compressor.

Pixels are not file size

Reducing pixels usually reduces image information, but a PNG result is not guaranteed to be smaller than the original JPG. If there is a file-size limit, use the compress-to-size tool and check the pixel requirements as well.

How do I know it's sharp enough?

Look at the smallest text, fine lines and edges in the image. Enlarging cannot restore detail. For printing, also check against the actual paper size and print resolution.
