How to compress an image to a target size

Browser tools that work without uploading your files.

Set the limit from the submission requirements

Check the file format, pixel size and file size the submission site requires, then enter the size limit. The tool counts 1 KB as 1024 bytes; if the site counts differently, leave some margin — for example, try 190 KB when the requirement is under 200 KB.

Automatic attempts and size protection

The tool first tries different encoding qualities; if that is not enough, it shrinks the image step by step within the size you allow. The minimum longest-edge setting protects pixel size but cannot guarantee text stays legible, so check the output preview. PNG does not use this lossy process.

What if the target can't be reached?

The tool shows that the limit was not reached and never offers a failed result as a success. Try a higher limit, a smaller minimum size, or crop away unneeded background first. Don't submit an unreadable ID or text image just to meet a file size; the result must meet the format, dimension and clarity requirements together.
