How to combine images into a PDF

Browser tools that work without uploading your files.

  1. Choose images — you can select several at once.
  2. Use Up and Down in the image list to set the page order; remove any images you don't need.
  3. Click Create file and download the combined PDF.

Size and sharpness

Each image becomes one page, and the page proportions follow the image. Images with a longest edge over 2400 pixels are scaled down and encoded as JPEG. File size depends on the number and content of images and is not guaranteed to be smaller than the originals. Images of text may lose some quality, so check the output.

Why can't I search the text?

This tool only places images into a PDF; it does not run OCR. To make text searchable, use OCR in the ZiruPDF desktop app and check the results.

How should I prepare phone photos?

First fix the orientation, crop away the table or background, and check that edges and text are sharp. The web tool has no perspective correction or OCR, so curled paper or glare means retaking the photo or using the scan feature.

Check the output

A one-image-per-page PDF is created in list order, and page proportions may differ. Large images are scaled down and encoded as JPEG, so original pixels and lossless quality are not guaranteed. Open the result again and check the order, sharpness and file size.
